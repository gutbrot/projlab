# Projlab 2026 - wiwiwi
## Fontos
- Mindenkinek csináltam egy saját branch-et, ezen kellene majd dolgozni és innen integrálni a main-be (ha nagyon professzionálisak akarnánk lennei beállíthatnánk egy kötelező PR-t, de az még lehet csak lassítana).
- Beállítottam egy maven check-et. Ez elméletben annyit ellenőriz, hogy szabályos szintaxist használunk-e, illetve, hogy futtatható-e.
- **!!** Meg kellene tartani az alábbi mappaszerkezetet, vagyis: src/java/\[valami package mappa\]/.java kiterjesztésű fájlok. Ez azért fontos, mert ezt a szerkezetet várja a github actions (ez a kódra vonatkozik, egyéb dologkat be lehet rakni mondjuk a gyökérben létrehozott res mappába). A .github mappa és a pom.xml békén kell hagyni, működik, ne nyúljunk hozzá. (Lehet majd berakom gitignore-ba és akkor nem kell vele lokálisan baszakodni).
- Azért is fontos, hogy az src-ben dolgozzunk, mert csak ott fog futni a maven check!
- Amúgy elvileg úgy állítottam be a check-et, hogy megfeleljen a követelményeknek, vagyis: Win 10 20H2 - JDC-Eclipse kari felhőbe telepített rendszeren kell futni. Megnéztem, ott az Eclipse verziója 2022-06 (4.24.0).
- Ahogy Matyiéknál láttam csak az src mappát kell becsomagolni és leadni.
